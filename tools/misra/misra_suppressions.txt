# Rule 15.5（関数の出口は末尾の1つのみとする）
#   本プロジェクトは引数検証・未初期化チェックで Det_ReportError() を報告した
#   直後に早期 return する構造を全モジュールで統一的に採用しており、AUTOSAR BSW
#   実装でも一般的な逸脱。単一出口へ書き換えるとネストが深くなり可読性が
#   かえって下がるため、プロジェクト全体で逸脱とする。
misra-c2012-15.5

# Rule 8.7（1つの翻訳単位からしか参照されない関数・オブジェクトは内部結合とする）
#   指摘は全て AUTOSAR 仕様で公開 API として規定された Module_Xxx 関数
#   （GetVersionInfo 等、現構成で他モジュールから呼ばれていないもの）。
#   仕様上の公開インタフェースであり static にはできないため逸脱とする。
misra-c2012-8.7
